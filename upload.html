이미지/영상 업로드

여기서 올린 사진·영상은 Cloudinary에 저장되고, 자동으로 압축/최적화된 주소가 생성됩니다 (q_auto,f_auto 적용). data.js에 붙여넣을 코드도 자동 생성됩니다. 이 페이지 주소는 아무한테도 공유하지 마세요.
Cloudinary 콘솔 → Settings → Upload → Upload presets에서 Unsigned로 된 preset 이름. 최초 1회만 입력하면 브라우저에 저장됩니다.
무료 플랜 용량 제한: 이미지 10MB / 영상 100MB. 그 이상은 미리 압축해서 올려야 합니다.

🔄 기존 이미지/영상 교체 (URL만 빠르게 받기)

파일 하나(또는 여러 개)만 올려서 최적화된 URL만 받고, data.js에서 바꾸고 싶은 기존 URL을 이걸로 직접 바꿔치기 하세요. 프로젝트 정보 입력 필요 없음.
교체할 사진/영상을 여기로 끌어다 놓거나 클릭해서 선택하세요

➕ 새 프로젝트 통째로 추가

1. 프로젝트 정보를 입력하고 → 2. 사진/영상을 끌어다 놓으면 → 3. 아래 코드가 자동 생성됩니다. 그 코드를 복사해서 js/data.js에 붙여넣으면 끝.
사진/영상을 여기로 끌어다 놓거나 클릭해서 선택하세요 (여러 개 가능, 첫 번째 이미지가 커버로 사용됨)
